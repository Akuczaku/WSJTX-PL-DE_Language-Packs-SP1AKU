AKTUALIZACJA STRONY GITHUB — 3 JĘZYKI

Po aktualizacji repozytorium GitHub pokaże na stronie głównej wybór:
- 🇵🇱 POLSKI -> README_PL.md
- 🇬🇧 ENGLISH -> README_EN.md
- 🇩🇪 DEUTSCH -> README_DE.md

W GitHub Desktop:
1. Skopiuj README.md, README_PL.md, README_EN.md i README_DE.md do głównego folderu repozytorium.
2. Zastąp istniejący README.md i README_EN.md.
3. Otwórz GitHub Desktop.
4. Summary: Add Polish English German pages
5. Kliknij Commit to main.
6. Kliknij Push origin.
7. Odśwież stronę repozytorium w przeglądarce.
