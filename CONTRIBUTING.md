# Contributing

Translation corrections are welcome.

When reporting a translation issue, please include:

1. language (PL or DE),
2. exact WSJT-X window/tab/menu,
3. screenshot if possible,
4. current text,
5. proposed corrected text.

For Qt translation changes, preserve placeholders such as `%1`, `%2`, `%n`, HTML markup, keyboard mnemonics, and technical amateur-radio terminology.
